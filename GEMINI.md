# Project: Noha Website

## Overview
Single-page mobile-first website for electronic music producer Noha.
Komi-style link-in-bio design.

## Tech Stack
- React (Vite)
- TypeScript
- Tailwind CSS (v4 via @tailwindcss/vite)

## Structure
- src/components: UI Components (Hero, FeaturedRelease, etc.)
- src/styles: (Unused, using Tailwind)
- src/App.tsx: Main layout
